# 中秋动态长卷美术资源清单与风格规范

> 文档版本：v1.0 Draft
> 更新日期：2026-08-24
> 用途：确定需要单独制作的透明 PNG 美术资源，并统一整站视觉风格、分层方式和交付规范。

## 1. 风格评审结论

本次参考包含两种纸艺方向：

1. 红色剪纸玉兔：节日感强、识别度高、造型可爱，但大面积使用容易产生春节生肖宣传页、儿童 IP 或电商促销页的观感。适合用作灯笼纹样、窗花、印章、节日贴纸和少量玉兔装饰。
2. 蓝金立体纸雕月宫：月白、黛蓝与暖金的配色更加克制，建筑、云层、月轮有清楚的前后纸层，天然适合图层平移、镜头推进、遮罩显影和灯光动画。

整站建议采用“蓝金立体纸雕长卷”作为主风格，红色剪纸作为不超过单屏视觉面积 15% 的局部强调。

### 1.1 主风格定义

- 主色：月白、黛蓝、暖金。
- 点缀色：少量朱砂与桂花黄。
- 材质：多层宣纸或卡纸切割边缘、轻微压纹、细薄纸层投影。
- 造型：宋式建筑、青绿山水、工笔式人物轮廓。
- 空间：像可以进入的纸雕舞台，前、中、后景明确。
- 动效：纸层展开、错位平移、遮罩显影、灯火渐亮、角色局部摆动。
- 气质：雅致、静谧、丰盈，不做全红国潮、电商礼盒或幼儿生肖风格。

## 2. 不需要制作 PNG 的资源

以下内容优先使用 CSS、SVG 或 Canvas 实现：

- 夜空渐变、月光、光晕和暗角。
- 普通云雾、远处雾层和空气透视。
- 星点、火星、光尘和飘落桂花粒子。
- 简单水波、水面高光和倒影扰动。
- 纸张噪点、颗粒、色彩滤镜和场景调色。
- 镜头前进路径、热点连线和导航轨迹。
- 简单祥云轮廓、窗格纹样、回纹和装饰边线。
- 圆形、月相和纯几何遮罩转场。

PNG 只承担具有明确造型、纸雕结构、人物特征和文化细节的资源。

## 4. 可选增强资源

- 飞鸟或雁群：五至十只不同姿态的远景剪影。
- 水中锦鲤：红白和金色锦鲤，用于倒影场景。
- 乌篷船与船夫：深色木船，船夫保留剪影。
- 远景行人：桥面、街市和城楼上的小比例人物。
- 宫灯纹样组：嫦娥、玉兔、桂树和月相四套灯面。
- 古琴、笛子、琵琶等乐器。
- 嫦娥、玉兔和吴刚的皮影版本。

## 5. 首批制作优先级

第一批建议控制在约 35 个资源：

- 核心角色：8个。
- 月宫建筑与道具：8个。
- 山水空间：6个。
- 灯市与灯笼：8个。
- 团圆场景：5个。

月饼剖面、更多植物前景与增强资源进入第二批。

## 6. 文件交付规范

- 使用透明背景 PNG 作为源资源，网站运行时转换为 WebP 或 AVIF。
- 默认按目标显示尺寸的两倍输出，以适配高分屏。
- 单个主要角色建议高度 1800—2600px；大型建筑建议宽度 3000—5000px。
- 所有需要动效的部件必须单独导出，并保持相同画布尺寸和原点。
- 资源边缘不得带黑底、白边或不一致的发光效果。
- 纸层光源统一为左上，纸层阴影落向右下。
- 只保留纸层自身的浅阴影，大范围环境阴影由网页统一生成。
- 文件名使用英文小写加连字符，例如 jade-rabbit-pounding-body.png。
- 同一资源的拆分文件放在同一目录，并附一张完整合成预览图。

## 7. 风格使用边界

- 蓝金纸雕负责主体场景、建筑、山水和主要角色。
- 红色剪纸只负责节庆强调，不超过单屏主要视觉面积的 15%。
- 可爱玉兔可以出现，但不能让整站变成儿童生肖宣传页。
- 建筑细节保持精致，但减少纯金堆砌，避免电商礼盒感。
- 纸雕资源的厚度、描边、光源和颗粒必须统一，否则图层平移时会产生拼贴感。
- 文字仍使用真实 HTML，不烘焙到 PNG 中，以保证清晰度、响应式与可访问性。

## 8. 参考图使用建议

### 红色剪纸玉兔

适合：

- 首屏短暂节日点题。
- 灯笼、窗花、贴纸和印章。
- 玉兔互动热点或移动端分享卡片。
- 红色场景中的局部高饱和强调。

不适合：

- 作为全部角色与建筑的统一配色。
- 长时间占据整屏背景。
- 与大量金色文字同时出现。
- 直接决定整站的可爱 IP 气质。

### 蓝金纸雕月宫

适合：

- 作为整站材质、配色和纸层厚度的基准。
- 月宫、古城、桥梁、亭台和山水场景。
- 镜头前进、图层平移、建筑显影和月门穿越。
- 通过窗光与灯光产生冷暖对比。

需要调整：

- 减少过密的金色花边，防止出现奢华礼盒感。
- 建筑之间应拉开前后距离，不要合成一个不可拆分的大图。
- 云层和光晕不烘焙进 PNG，应由网页动态生成。
- 每座建筑、栏杆、月轮和主要云纹独立交付。
