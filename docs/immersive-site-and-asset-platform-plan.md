# 月满人间：沉浸式动态长卷与素材平台总体规划

> 版本：v1.0 Draft
> 日期：2026-08-30
> 技术基础：React + TypeScript
> 主视觉：蓝金立体纸雕长卷
> 文档用途：确定主站体验、页面内容、镜头与动画、文字、交互、素材引用以及 MinIO 素材管理架构。

## 1. 项目定义

“月满人间”不是传统节日官网，也不是由卡片、栏目和图文区块组成的介绍页。它是一幅可以操控镜头游览的中秋动态长卷。

用户滚动时，镜头沿一条隐藏的 SVG 贝塞尔路径穿过月门、月宫、山水、灯市、宴席与万家灯火。文化内容成为场景中的题跋、匾额、壁画、灯谜、卷轴和可发现热点，而不是普通网页卡片。

项目需要同时满足两个目标：

1. 视觉体验：以纸雕美术资源、图层差速、显影与镜头移动形成强烈的空间感。
2. 内容可达：用户可以随时通过“月下舆图”跳转场景，不被线性任务或收集机制限制。

## 2. 核心设计原则

### 2.1 画面先于界面

- 主站不使用常规顶部导航、白色内容卡片和后台式栅格。
- 导航隐藏在“月下舆图”、场景边缘题签和可交互地标中。
- 文字嵌入卷轴、墙面题跋、灯面、石碑和水面倒影。
- 所有界面控件默认弱化，仅在用户需要时显现。

### 2.2 镜头前进不等于任务流程

- 滚动负责控制镜头位置，不代表章节解锁。
- 用户可以正向、反向滚动，也可以从舆图直接跳至任意场景。
- 不设置进度百分比、关卡、积分、月华收集或完成奖励。
- 场景内容独立可读，不要求先理解上一幕。

### 2.3 纸雕空间规则

- 每个场景至少包含远景、中远景、中景、近景、遮挡前景和特效层。
- 主光源统一来自左上方，纸层阴影落向右下。
- 建筑、人物与植物使用 PNG/WebP；雾、光、粒子、背景渐变使用 CSS/Canvas。
- 蓝金纸雕为主体，朱砂剪纸仅用于灯笼、窗花、印章和节庆强调。
- 同一屏幕中高饱和红色面积不超过约 15%。

### 2.4 内容不是装饰

每个交互至少承担一种作用：

- 解释中秋历史或文化。
- 展示地域差异。
- 让用户理解神话、诗词或月相知识。
- 帮助用户在空间中定位和跳转。
- 提供可控的声音与视觉反馈。

## 3. 路由与页面结构

| 路径 | 页面名称 | 作用 |
| --- | --- | --- |
| / | 月门入口 | 建立世界观，进入长卷或打开月下舆图 |
| /journey | 月行千里图 | 主体验，一幅连续可滚动的动态纸雕长卷 |
| /atlas | 月下舆图 | 非线性场景地图，可直接跳至任意长卷坐标 |
| /archive | 月下文库 | 提供可搜索、可复制、适合 SEO 与无障碍阅读的文化正文 |
| /admin/assets | 美术素材库 | 上传、分类、版本管理和查询 MinIO 素材 |
| /admin/scenes | 场景配置 | 后续版本：为每个场景绑定资源键、图层和动画参数 |

第一阶段实现 /journey、/atlas 与 /admin/assets；/archive 可在主体验稳定后补充。

## 4. 全局体验机制

### 4.1 滚动镜头

- 页面创建一条隐藏 SVG 路径，记录镜头的 X、Y、缩放和轻微旋转。
- 用户纵向滚动，内部镜头可横向、斜向或纵深移动。
- 不直接移动整张超大图片，而是根据镜头位置计算每个图层的位移。
- 远景移动速度约为镜头的 0.15 倍，中景 0.45—0.7 倍，近景 1—1.3 倍。
- 近景快速掠过时添加轻微模糊，强化纵深但不影响主体阅读。

### 4.2 月下舆图

- 屏幕右上角保留一枚小型月纹按钮。
- 点击后，当前画面收缩成一张横向长卷地图。
- 地图展示月门、月宫、山水、灯市、宴席和万家灯火六个地标。
- 点击地标，镜头通过云雾遮罩跳转到对应坐标。
- 舆图只表示位置，不显示完成度。
- 键盘用户可直接通过列表选择场景。

### 4.3 文化热点

热点不使用普通圆形按钮，而采用以下形式：

- 金色细线沿物体轮廓短暂流动。
- 灯笼轻轻亮起。
- 印章从半透明变为清晰。
- 桂花枝落下一朵花。
- 匾额边缘出现月白描光。

聚焦或悬停后显示短题签；点击后由场景材质自然展开内容。

### 4.4 环境声音

- 默认关闭，首次不自动播放。
- 用户开启后，根据场景交叉混音：风声、虫鸣、水声、灯市人声、木鱼或古琴泛音。
- 场景跳转时声音渐入渐出，不突然切换。
- 始终提供显眼的静音按钮。
- 不将朗读与环境音绑定，诗词朗读单独触发。

### 4.5 文字显影

- 短标题：金色矢量线描后填充。
- 诗句：模拟墨迹书写，但最多 1.2 秒完成。
- 正文：宣纸卷轴或墙面题跋淡入，不逐字慢速播放。
- 重要说明保留真实 HTML 文本，不烘焙进图片。

## 5. 页面一：月门入口（/）

### 5.1 页面目标

在十秒内让用户理解这是一幅“可以进入的中秋长卷”，并提供主体验与自由地图两个入口。

### 5.2 初始画面

- 全屏深黛蓝夜色。
- 画面中心不是完整月亮，而是一道由纸层组成的月白圆形门。
- 门内只能看见远处月宫的一部分轮廓。
- 左右前景分别伸入桂花枝和深色松枝。
- 近景有两三层半透明 CSS 雾气缓慢横移。
- 鼠标移动时，门框、远山与枝叶产生轻微视差。

### 5.3 页面文字

主标题：

“月满人间”

副题：

“一幅可以走进去的中秋长卷”

导语：

“循一线月光，越过月宫、山河与灯火。
所见不是章节，而是同一轮月亮下的万千人间。”

入口文字：

- “入画”——进入 /journey
- “展开舆图”——进入 /atlas
- “开启声音”——独立环境音按钮

### 5.4 入场动画

1. 黑场中出现一条暖金弧线。
2. 弧线沿圆周描画，形成月门轮廓。
3. 门内云层由中心向两侧分开。
4. 月宫窗灯逐盏亮起。
5. 标题像压印在纸上，从浅凹痕逐渐显色。
6. 两个入口在动画完成前即可操作，不强迫用户等待。

### 5.5 交互

- 鼠标移向“入画”，月门内部画面向前推进约 3%。
- 点击“入画”，镜头穿过月门，圆形门框扩大并覆盖屏幕，进入长卷。
- 点击“展开舆图”，月门横向展开为地图卷轴。
- 点击桂花枝，出现一句短题签：“桂子月中落，天香云外飘。”
- 支持 Enter 直接进入主体验，Esc 关闭声音或舆图。

## 6. 页面二：月行千里图（/journey）

主体验由七幕连续场景构成。场景之间没有普通页面切割，通过云、月门、水面、屋檐和窗框完成遮挡转场。

### 6.1 序幕：穿云见月

#### 画面

- 镜头从月门内部向前移动。
- 多层 CSS 云雾以不同速度掠过。
- 远处完整月轮逐渐从云后显露。
- 一只仙鹤从右下方飞向月宫，承担视线引导。

#### 文字

题签：

“八月十五，三秋恰半。”

短文：

“中秋之名，取秋季正中之意。
从祭月、赏月到家人团聚，一轮圆月承载了千年的心意。”

#### 动效

- 月轮由弦月遮罩过渡为满月。
- 云层进入镜头时短暂模糊。
- 文字随着最后一层云散去而显现。

#### 交互

- 点击月轮可拖动查看八个月相。
- 点击仙鹤，镜头短暂跟随其飞行方向。
- 月相说明以环绕月轮的弧形文字出现。

### 6.2 第一幕：月宫清辉

#### 画面

- 蓝金纸雕月宫占据场景主体。
- 主殿、侧殿、长廊和月洞门分为多个深度层。
- 桂花神树位于左侧中景，玉兔药臼位于右侧近景。
- 嫦娥出现在主殿栏杆后，不长期占据画面中心。

#### 文字

主题：

“月宫并非一则故事”

导语：

“嫦娥、玉兔、吴刚与蟾宫，
是古人寄给月亮的四种想象。”

热点题签：

- 嫦娥：“奔月 · 清辉长守”
- 玉兔：“捣药 · 仁心济世”
- 吴刚：“伐桂 · 生生不息”
- 蟾宫：“折桂 · 金榜题名”

#### 动效

- 建筑先显示金色线稿，再由纸层从后向前显影。
- 窗灯根据镜头距离逐盏点亮。
- 桂树叶群分层轻摆，金桂以 Canvas 粒子少量飘落。
- 玉兔耳朵和药杵做低频循环动画。
- 嫦娥披帛只做轻微摆动，不做持续飞舞。

#### 交互

- 点击玉兔药杵，药臼升起月白粉尘，墙面显现“玉兔捣药”的历史图像说明。
- 点击桂树伤痕，树皮发光并展开吴刚传说。
- 点击嫦娥，主殿窗格闭合成剪影戏，讲述传说的不同版本。
- 点击蟾宫印章，显示“蟾宫折桂”与科举文化。
- 所有内容都标注“神话传说，非历史事实”。

#### 场景转场

镜头穿过月宫长廊的最后一扇月洞门。门内不是宫殿，而是一片青绿山水。

### 6.3 第二幕：山水诗境

#### 画面

- 远、中、近三层青绿山水横向展开。
- 河流形成镜头前进路径。
- 山间亭台、临水石桥、松枝和芦苇形成空间遮挡。
- 月亮倒映在水面，倒影稍有波动。

#### 文字

主题：

“同一轮月，不同的人间心事”

诗词节点：

1. 张九龄：“海上生明月，天涯共此时。”
2. 杜甫：“露从今夜白，月是故乡明。”
3. 苏轼：“但愿人长久，千里共婵娟。”
4. 苏轼：“此生此夜不长好，明月明年何处看。”

辅助说明：

“古人将无法抵达的故乡、无法相见的人，交给月亮代为照看。”

#### 动效

- 山体从线稿到设色逐层显影。
- 镜头横向移动时，近景松枝快速掠过。
- 河面通过位移滤镜产生缓慢倒影。
- 诗句沿山脊或水面路径出现，不使用普通文本框。
- 亭台灯笼在诗句被选中时点亮。

#### 交互

- 点击不同亭台选择诗词主题：团圆、怀人、思乡、赏月。
- 点击水中月影，画面短暂上下翻转，显示诗词白话解读。
- 开启朗读后，只朗读当前诗词。
- 用户可拖动横向长卷，也可继续滚动让镜头自动前进。

#### 场景转场

一盏从桥边升起的红色灯笼逐渐放大，镜头进入灯笼内部，再从古城另一盏灯中穿出。

### 6.4 第三幕：古城灯市

#### 画面

- 木构街屋、城楼、月饼铺、酒摊和街头灯架组成纵深街道。
- 红色宫灯、玉兔纸灯和莲花灯形成主要暖色。
- 背景保持黛蓝，红色面积受控。
- 人物使用半剪影纸雕造型，避免抢夺主体。

#### 文字

主标题：

“灯火照人间，风俗各不同”

场景说明：

“祭月、走月、舞火龙、饮桂花酒。
不同水土，用不同方式分享同一夜月光。”

风俗热点：

- “祭月拜月 · 全国多地”
- “走月亮 · 江南地区”
- “舞火龙 · 广东与香港”
- “燃灯赏灯 · 湖广与岭南”
- “饮桂花酒 · 江南地区”
- “吃柚子 · 闽南与台湾”

#### 动效

- 灯笼按镜头前进方向逐盏亮起。
- 人物剪影做少量走动、抬手和提灯摆动。
- 舞火龙横向穿过远景，火星由 Canvas 生成。
- 商铺招牌通过纸片翻转显现。
- 场景环境音从安静风声过渡为克制的市集人声。

#### 交互

- 点击不同灯笼，灯面展开为对应地域习俗。
- 玉兔灯展示灯彩制作方式。
- 舞火龙经过时可以点击暂停，查看习俗来源和地区。
- 酒摊可点击桂花酒坛，显示桂花与中秋的关系。
- 所有热点可独立查看，不构成答题或收集。

#### 场景转场

月饼铺的圆形蒸笼打开，镜头俯冲进入蒸笼，圆形遮罩变成下一幕的月饼剖面。

### 6.5 第四幕：一口团圆

#### 画面

- 画面像一张展开的中秋食案。
- 广式、苏式、滇式和京式月饼排列在不同纸层。
- 桂花酒、柚子、秋蟹、芋头和茶具形成辅助构图。
- 背景使用暖米色纸张，暂时离开深色夜景。

#### 文字

主标题：

“月饼不止一种，团圆只有一种”

说明：

“从岭南到江南，从北方到高原，
不同风土，被包进一枚圆饼。”

月饼文案：

- 广式：“皮薄馅丰，莲蓉与咸蛋黄层层相合。”
- 苏式：“酥层分明，甜咸皆有江南风味。”
- 滇式：“云腿与蜂蜜相遇，咸甜交织。”
- 京式：“形制端正，传统印纹留住北方气质。”

#### 动效

- 月饼以纸雕分解方式展开，不做写实食物爆浆。
- 用户靠近时，月饼表面纹样沿金线描亮。
- 剖面层向两侧分离，显示馅料结构。
- 桂花酒杯出现轻微蒸汽，使用 CSS 实现。
- 食案前景随镜头产生浅景深。

#### 交互

- 拖动月饼可旋转观察纹样。
- 点击切面查看流派、常见馅料和地域。
- 点击柚子、秋蟹等节食查看谐音和时令意义。
- 内容关闭后食物自动复位。

#### 场景转场

圆形月饼与天空中的月轮重合。暖米色背景逐渐变回夜色，镜头从食案拉远至一扇中式窗户。

### 6.6 第五幕：人间团圆

#### 画面

- 镜头从窗外看向室内家宴。
- 深色窗框为近景，屋内为暖金色纸雕场景。
- 家人围坐圆桌，但人物以侧影表现，不强调具体身份。
- 窗外桂树、屋檐和远处月亮保持清冷蓝色，形成冷暖对比。

#### 文字

主标题：

“月圆是天象，团圆是人心”

正文：

“中秋的意义，从来不只在天上的月亮。
它也在一张圆桌、一盏灯、一封未寄出的问候里。”

人物题签：

- “同席”
- “归家”
- “遥祝”
- “共此时”

#### 动效

- 窗纸从暗到明，屋内人物逐层出现。
- 举杯动作缓慢且只执行一次。
- 室内灯光呼吸式变化控制在极小范围。
- 桂树投影落在窗纸上，随风轻摆。
- 环境声音从市集过渡到室内茶水、碗筷和轻声交谈。

#### 交互

- 点击不同窗格，查看各地家庭过中秋的片段。
- 点击空座位，显示“无法归家，也可以共赏同一轮月”的内容。
- 点击桌上月饼盒，连接前一幕的饮食内容。
- 用户可选择生成一张不含个人信息的中秋诗句分享图，作为后续增强功能。

#### 场景转场

镜头持续向后拉远，最初的一扇窗变成城中万千灯火中的一格。

### 6.7 终幕：万家共月

#### 画面

- 镜头拉至高空，古城、山河、月宫形成一幅完整长卷。
- 万家灯火在地面形成与天上圆月呼应的圆形构图。
- 前面出现过的仙鹤从画面上方飞过。
- 月下舆图的完整路径以细金线短暂显现。

#### 文字

主标题：

“海上生明月，天涯共此时”

结束语：

“愿所有相隔千里的思念，
都能在今夜，被同一轮月光照见。”

操作：

- “再游一遍”
- “展开月下舆图”
- “进入月下文库”
- “静静赏月”——隐藏界面，保留画面和环境音

#### 动效

- 全卷各处灯火依次点亮，但不使用烟花。
- 标题从月光中显现。
- 停留时画面进入低频环境循环，不自动跳转或倒计时。

## 7. 页面三：月下舆图（/atlas）

### 7.1 视觉

- 一张横向纸雕地图，不使用普通导航列表作为主视觉。

## 10. MinIO 存储架构

### 10.1 推荐结构

- MinIO：保存原始 PNG、WebP、AVIF、缩略图和历史版本。
- 业务数据库：保存资源键、名称、场景、分类、版本、尺寸、状态、引用关系和 MinIO 对象键。
- 后端服务：负责权限、预签名上传、资源审核、版本切换和场景清单。
- CDN 或反向代理：负责公开资源分发。
- React 管理页：只调用后端 API，不直接持有 MinIO Access Key 或 Secret Key。

### 10.2 Bucket 建议

- midautumn-assets-private：原始 PNG、PSD 导出物与待审核资源。
- midautumn-assets-public：审核通过的 WebP、AVIF、SVG 和缩略图。
- midautumn-assets-archive：旧版本与归档资源。

### 10.3 对象键规范

midautumn/{environment}/{scene}/{category}/{slug}/v{version}/{variant}.{format}

示例：

midautumn/prod/moon-palace/architecture/main-hall/v3/source.png
midautumn/prod/moon-palace/architecture/main-hall/v3/display.avif
midautumn/prod/moon-palace/architecture/main-hall/v3/fallback.webp
midautumn/prod/moon-palace/architecture/main-hall/v3/thumb.webp

### 10.4 上传流程

1. 管理员在 /admin/assets 选择文件并填写名称、场景和类型。
2. 前端请求 POST /api/admin/assets/upload-session。
3. 后端验证文件类型、大小和权限，创建草稿记录。
4. 后端返回一次性 MinIO 预签名 PUT URL。
5. 浏览器直接把文件上传到 MinIO，文件流不经过业务服务器。
6. 前端调用 POST /api/admin/assets/{id}/complete。
7. 后台任务检查透明通道、尺寸和文件完整性。
8. 后台生成缩略图、WebP 与 AVIF。
9. 管理员审核后状态变为 ready。
10. 场景清单版本递增，CDN 缓存按新地址刷新。

### 10.5 API 草案

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | /api/admin/assets | 分页搜索素材 |
| GET | /api/admin/assets/{id} | 获取详情与版本 |
| POST | /api/admin/assets/upload-session | 创建预签名上传会话 |
| POST | /api/admin/assets/{id}/complete | 通知上传完成 |
| PATCH | /api/admin/assets/{id} | 修改名称、分类和场景 |

### 10.7 权限与安全

- MinIO 密钥只存在于服务端环境变量或密钥管理系统。
- 管理页必须登录后访问，推荐角色：admin、artist、reviewer。
- artist 可以上传和编辑草稿；reviewer 可以发布；admin 可以归档和配置存储。
- 上传会话限制 MIME、文件大小、对象键和有效时间。
- 原始素材桶设为私有。
- 公开桶只保存已审核的衍生格式。
- SVG 上传需要服务端清理脚本和外部引用。
- 文件名不直接作为对象键，避免特殊字符和路径穿越。
- 删除操作默认进入归档，不直接物理删除 MinIO 对象。
- 发布后通过校验和避免重复文件。

## 11. 前端资源加载策略

- 进入场景前预加载当前场景必须资源和下一场景主资源。
- 远景优先加载低分辨率 WebP，再切换 AVIF 或高清版本。
- 透明角色优先使用 WebP；兼容问题时回退 PNG。
- 大型建筑按图层拆分，不加载一张超大合成图。
- 离开两个场景以上的资源允许释放纹理和对象 URL。
- 移动端使用独立 manifest，减少前景层和资源尺寸。
- 每个场景必须定义失败占位，资源加载失败不能造成白屏。
- 关键文字始终由 HTML 渲染，图片失败时仍可理解内容。
